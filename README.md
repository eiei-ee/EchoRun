# 3D 无尽跑酷 Temple Run

基于 团结引擎 (Unity 2022.3) / C# 开发的 3D 无尽跑酷游戏 Demo，支持 WebGL 浏览器即玩与 Android 双端运行。

> 项目定位：Unity 游戏开发实习作品 / 3D 跑酷玩法 Demo

## 试玩

**浏览器即玩：https://eiei-ee.github.io/TempleRun/**

支持键盘操作：A/D 或 ← → 左右变道，W 或 ↑ 跳跃，S 或 ↓ 滑铲。

## 核心功能

- 三车道移动：左右切换、跳跃、滑铲
- 无限道路：直线路段与左右 90° 转弯路段持续生成
- 动态生成：金币、障碍物、道具随道路生成
- 对象池复用：道路、金币、障碍物、道具统一回收复用
- 障碍系统：Low / High / Barrier 三类障碍，对应滑铲、跳跃、变道处理
- 安全车道：生成逻辑保证每段道路至少存在可通行路线
- 金币引导：安全车道生成主金币线，相邻车道生成奖励金币线
- 道具系统：磁铁、加速、护盾、双倍金币
- 游戏状态：主菜单、游戏中、暂停、死亡结算、重新开始
- UI 流程：HUD、暂停面板、设置面板、角色选择、结算面板
- 数据持久化：最高分、总金币、音量、帧率、角色配置本地保存
- 多端输入：键盘、触屏滑动、编辑器鼠标输入

## 技术实现

### 程序化道路生成

TrackManager 负责道路段生成、转弯路段拼接和动态物体放置。直线路段先规划安全车道，再生成障碍物、金币和道具，避免三车道全堵或金币/障碍重叠。

### 对象池

道路段、金币、障碍物和道具通过对象池复用，减少运行时频繁 Instantiate / Destroy 带来的性能开销。

### 安全车道与金币引导

每段道路维护一条安全车道，金币主线放在安全车道上提示前进路线，相邻车道生成短金币线作为风险奖励。

### 道具系统

磁铁（自动吸金币）、加速（提升速度+无敌）、护盾（抵挡一次障碍）、双倍金币，道具效果可叠加。

## 技术栈

团结引擎 (Unity 2022.3) · C# · Unity Test Framework · WebGL · Android
