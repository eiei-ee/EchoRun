# ECHO//RUN v0.2.0-alpha.1 — local release candidate

Status: **locally committed, tagged, and verified; not published**. This
document records the exact candidate state prepared on 2026-08-16. The local
annotated tag is not evidence of a remote GitHub tag, GitHub Release, Pages
deployment, Windows download, or Android download.

## Player-facing result

The short “perform three prompted actions, break the contract, pass the echo,
end the run” arc is replaced by a staged duel:

1. **Detection** observes the player for 20 seconds.
2. **Reveal** exposes the learned habit and contract over 8 seconds.
3. **Resistance** opens the first 0-to-100 stability objective.
4. **Counterattack** resets stability to 55% and strengthens the echo response.
5. **Rewrite** becomes the long pursuit phase; its first 32 seconds accelerate
   only next-generation learning.
6. **Finale** starts in the last 25 seconds and resolves the race.

Calibration targets approximately 75 seconds and a challenge approximately 190
seconds. Victory still requires both a broken contract and a player lead at the
finish. The first collision slows the player into recovery; the second ends the
run.

## AI-generation integrity

- The active generation is one versioned snapshot of policy weights, sequence
  transitions, style, pace, clarity, and generation number.
- Current inputs train a separate pending state.
- Only a finish with contract completion and player lead promotes the pending
  state.
- Failure, collision, abandonment, and same-generation retry preserve the
  active snapshot.
- Interrupted calibration with enough minimum evidence may seed a fuzzy echo;
  reduced clarity is exposed instead of treating it as complete calibration.

## Attribution and safety repairs

- Director observations settle when the player crosses the generated route
  window, not when more segments happen to be pre-generated.
- Contract-rewritten track plans are excluded from contextual-bandit rewards.
- Pressure lowers turn probability but turns remain obstacle-free.
- Lane preference is measured relative to the offered route center.
- Only explicitly tagged contract marker coins advance lane contracts.
- Deterministic route validation remains authoritative.

## Known limits before publication

- The existing public WebGL URL may still serve an older build.
- A Windows standalone candidate and Android package were not produced in this
  verification pass, so neither is claimed as a current official download.
- Full-run balance still needs human playtesting with both fresh and mature
  saved profiles, especially first-generation echo lead and the 190-second
  dramatic curve.
- The reviewed source is committed and locally tagged. Only unrelated,
  user-owned untracked assets remain outside the candidate.

## Publication checklist

1. Keep the unrelated local assets outside source and release artifacts.
2. Push the reviewed source branches and annotated tag only after maintainer
   approval.
3. Deploy the already verified WebGL artifact whose `build-info.json` matches
   the tagged source commit.
4. Verify the public canvas, console, inputs, gameplay, and published hashes.
5. Create the GitHub Release only after the deployed files match the tested
   local candidate.
